# Rick and Morty Wiki Application 🛸

A web-based character encyclopedia for the **Rick and Morty** universe. This application fetches data from the [Rick and Morty API](https://rickandmortyapi.com/) and presents characters in an interactive, paginated gallery. Users can view detailed character profiles by clicking on individual cards, which open in a new tab.

## 🚀 Features

- **Character Gallery**
  - Displays character **image**, **name**, **species**, and **status**
  - **Pagination** with Next/Previous buttons
  - **Clickable character cards** to open detailed view in a new tab

- **Character Detail Page**
  - Fetches data using the character's unique **ID**
  - Displays detailed info: image, name, gender, species, type, origin, current location, episode count/names

- **Live Clock Footer**
  - Dynamically updates every second
  - Format: `HH:MM:SS Day Date` (e.g., `14:30:45 Friday March 17, 2025`)
